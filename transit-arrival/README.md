# 도착알리미 (transit-arrival)

지정한 버스·지하철이 **내가 고른 정류장** 또는 **현재 위치에서 가장 가까운 등록 정류장**에 언제 도착하는지를
Android **홈 화면 위젯**과 **잠금화면 알림**으로 보여주는 개인용 앱입니다.

- 서버·계정·광고·분석 도구가 없습니다. 모든 데이터는 기기 안에만 있습니다.
- 앱 실행 코드에 외부 라이브러리가 **0개**입니다(Android 프레임워크만 사용).
- 위치는 기기 안에서 거리 계산에만 쓰이고, 저장·전송되지 않습니다. → [SECURITY.md](SECURITY.md)
- 전체 작업 기록 → [docs/WORKLOG.md](docs/WORKLOG.md)

## 동작 방식

| 표시 위치 | 방법 |
|---|---|
| 홈 화면 | 위젯(4×2). 탭하면 실시간 갱신 시작, "설정"을 탭하면 앱 열기 |
| 잠금화면 | 실시간 갱신 중 표시되는 진행 중 알림(내용 표시 여부 선택 가능). 잠금화면 위젯을 지원하는 기기에서는 위젯도 추가 가능 |

실시간 갱신은 사용자가 시작했을 때만, 설정한 시간(기본 20분) 동안 30초 간격으로 동작하고 스스로 끝납니다.
그 외 시간에는 위젯이 약 30분마다 한 번 갱신됩니다(Android 위젯의 최소 주기).

"가장 가까운 정류장"은 **내가 등록해 둔 정류장들 중에서** 고릅니다. 주변 정류장을 서버에 물어보는 방식은
현재 위치가 서버로 나가기 때문에 일부러 넣지 않았습니다. 집 앞·회사 앞 정류장을 각각 등록해 두면,
있는 곳에 따라 자동으로 바뀝니다.

## 지원 범위와 데이터 출처

| 종류 | 출처 | 인증키 발급처 | 검증 상태 |
|---|---|---|---|
| 버스(전국, 서울 제외) | 국토교통부 TAGO `apis.data.go.kr` | 공공데이터포털(data.go.kr) | HTTPS 응답·오류 형식 실제 확인. 정상 응답은 키가 없어 공개 래퍼 소스와 대조 |
| 지하철(수도권) | 서울시 `swopenapi.seoul.go.kr` | 서울 열린데이터광장 | **미검증** (아래 참고) |
| 서울 버스 | 서울시 `ws.bus.go.kr` | 공공데이터포털 | **미검증** (아래 참고) |

> **미검증 항목**: 개발 환경(해외 서버)에서 서울시 두 호스트는 HTTPS 연결이 끊겨 실제 응답을 확인하지 못했습니다.
> 이 앱은 HTTPS로만 연결하며 평문(HTTP)으로 절대 내려가지 않습니다. 따라서 해당 서버가 HTTPS를 지원하지 않으면
> 앱에 연결 오류("네트워크에 연결할 수 없습니다" 또는 "보안 연결(HTTPS)에 실패했습니다")가 표시되고 그 종류는 사용할 수 없습니다(인증키가 평문으로 새는 것보다 낫다고 판단).
> 실제 기기에서 확인이 필요합니다.

### 인증키 받기 (무료, 본인 명의)

1. **전국 버스**: data.go.kr 로그인 → "국토교통부_(TAGO)_버스도착정보", "국토교통부_(TAGO)_버스정류소정보",
   "국토교통부_(TAGO)_버스노선정보" 세 가지를 각각 활용신청 → 마이페이지의 일반 인증키(Decoding 또는 Encoding 아무거나).
2. **지하철**: data.seoul.go.kr → "서울시 지하철 실시간 도착정보" → 실시간 지하철 인증키 신청.
3. **서울 버스**: data.go.kr → "서울특별시_정류소정보조회 서비스" 활용신청.

키는 앱의 "인증키" 항목에 붙여넣습니다. 기기의 보안 저장소 키로 암호화되어 저장되며 화면에 다시 표시되지 않습니다.

## 빌드

필요한 것: JDK 17 이상, Android SDK(플랫폼 36). Android Studio가 있으면 이 폴더를 열면 됩니다.

```bash
cd transit-arrival
./gradlew :app:testDebugUnitTest :app:lintDebug   # 단위 테스트 + 정적 검사
./gradlew :app:assembleDebug                      # app/build/outputs/apk/debug/app-debug.apk
```

`./gradlew`는 Gradle 배포본의 SHA-256을 확인하고, 모든 빌드 의존성은
`gradle/verification-metadata.xml`의 해시와 일치해야만 사용됩니다.

### 본인 키로 서명한 릴리스 빌드 (권장)

```bash
# 1) 서명 키 생성 (한 번만, 저장소 밖 안전한 곳에 보관. 절대 커밋하지 마세요)
keytool -genkeypair -v -keystore ~/transit-release.jks -alias transit \
        -keyalg RSA -keysize 4096 -validity 10000

# 2) transit-arrival/keystore.properties 작성 (.gitignore에 포함되어 있음)
storeFile=/home/me/transit-release.jks
storePassword=...
keyAlias=transit
keyPassword=...

# 3) 빌드 및 서명 확인
./gradlew :app:assembleRelease
$ANDROID_HOME/build-tools/36.1.0/apksigner verify --print-certs app/build/outputs/apk/release/app-release.apk
```

## 설치

1. 휴대폰을 USB로 연결(개발자 옵션 → USB 디버깅)하고 `adb install -r app-release.apk`.
   파일을 메신저·메일·클라우드로 옮기지 않아도 되므로 가장 안전합니다.
2. 설치 후 USB 디버깅을 다시 끄세요.
3. 파일로 옮겨 설치할 경우, 설치 전에 PC에서 계산한 `sha256sum` 값과 일치하는지 확인하세요.

GitHub Actions가 만든 디버그 APK는 빌드마다 서명 키가 달라 업데이트 설치가 되지 않고,
키를 본인이 통제하지 않으므로 시험용으로만 쓰세요.

## 사용

1. 앱 실행 → 인증키 설정 → 정류장/역 추가(이름 검색 → 선택).
2. 필요하면 정류장마다 "노선"으로 보고 싶은 버스 번호(예: `7, 7-1`)나 호선·방면(예: `2호선, 성수행`)만 남깁니다.
3. "가장 가까운 등록 정류장" 모드를 쓰려면 위치 권한을 허용합니다.
   지하철역은 API가 좌표를 주지 않으므로, 그 역에 있을 때 "여기로 좌표"를 눌러 기기에 저장합니다.
4. 홈 화면을 길게 눌러 위젯 "도착알리미"를 추가합니다.
5. 위젯을 탭하거나 앱에서 "실시간 시작"을 누르면 잠금화면 알림과 위젯이 30초마다 갱신됩니다.

## 알려진 한계

- 실시간성은 공공 API의 갱신 주기(보통 수십 초)와 하루 호출 한도에 묶입니다. 30초 × 20분 = 40회/세션.
- 백그라운드 위치 권한을 요청하지 않으므로, 30분 주기 자동 갱신 때는 새로 측위하지 않고 마지막으로 고른 정류장을 씁니다.
- "GPS만 사용"을 켜면 실내·지하에서 위치를 못 잡을 수 있습니다. 이때는 마지막으로 고른 정류장을 유지합니다.
- 잠금화면 위젯은 기기·Android 버전에 따라 지원되지 않습니다. 알림 방식은 모든 기기에서 동작합니다.
- 에뮬레이터/실기기에서의 실행 시험은 수행하지 못했습니다(개발 환경에 기기 없음). 컴파일·단위 테스트·lint까지 확인했습니다.
